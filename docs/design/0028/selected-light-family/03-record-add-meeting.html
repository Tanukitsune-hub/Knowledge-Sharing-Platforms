記録を追加

記録種別を選び、親recordを先に保存してから関連資料を追加する。

設計参照 · 架空データ

記録種別

面談とデータ受領は同じrecord creation surfaceで開始します。資料だけを独立登録するrouteはありません。

登録順序

  1. 親記録を先に登録入力内容を保存し、stable Meeting_ID を発行
  2. 親IDを確認資料登録は確定済みの親record contextから開始
  3. 資料を登録成功した各ファイルの Document_ID を親recordへ追加
親記録の作成に失敗した場合、Pitchbook / file registrationは0件のままです。親記録は保持し、ファイル単位の部分失敗だけを再試行します。
