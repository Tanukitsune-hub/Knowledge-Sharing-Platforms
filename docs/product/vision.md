# Product Vision

## Purpose

面談記録とPitchbook等の投資関連資料を継続的に蓄積し、過去に得た情報を必要なときに簡単に取り出せる状態を作る。

対象はプライベートアセット業務を中心とするが、現段階では複雑な「ナレッジ共有プラットフォーム」を先に作ることを目的としない。

## Core user experience

### 面談記録

利用者はGoogle Sheets上のシンプルな入力画面から面談記録を登録する。

共通項目は少数に抑える。現時点の候補は以下。

- 日付
- 面談先
- 面談場所
- チーム
- アセットクラス
- その他、今後必要性が確認された最小限の項目

面談内容そのものは自由記載とする。

登録するとApps Scriptが一貫した形式のGoogle Docsを生成し、Shared Driveへ保存する。同時にGoogle Sheets側へ最低限の索引情報とドキュメントへのリンクを残す。

### Pitchbook等の資料

Pitchbookその他の原資料はShared Driveへ継続的に保存する。利用者に複雑な登録作業を要求しないことを優先する。

## Long-term outcome

将来的には、面談記録とPitchbook等を横断して、必要な情報を検索・参照・質問できる状態を目指す。

ただし、検索方式、AI Q&A、RAG、Vector DB、専用UI等は現時点では未決定であり、蓄積層を安定させた後に必要性を見て選択する。

## Principles

- シンプルさを最優先する。
- 人間の入力負荷を増やしすぎない。
- 面談本文は自由記載のまま残す。
- 原資料を正本として維持する。
- Google Workspaceを基本の保管・入力環境とする。
- 将来の検索技術を今の保存形式へ過度に埋め込まない。
- 実装していない機能を計画上の既定路線にしない。

## Explicit non-goals for now

- AppSheet前提のUI設計
- 独自Webアプリの先行開発
- Wiki、SNS、Like、コメント等の共有機能
- Gmail全体の取り込み
- 複雑なタグ体系
- 自動分類の作り込み
- Vector DBや高度なRAG基盤の先行導入
- AIによる投資判断や正式記録の自動確定

## Current phase

詳細設計前のベースライン確定段階。入力項目、テンプレート、命名規則、フォルダ構成、検索方式等は今後の検討で決める。
