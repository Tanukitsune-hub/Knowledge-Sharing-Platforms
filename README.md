# Knowledge Sharing Platforms

部内に散在する面談記録、面談資料、人物情報、ファンド情報、疑問点、フォローアップ事項を、利用者の追加負担を最小限に抑えながら再利用可能なナレッジへ変換するための共有基盤プロジェクトです。

## 目標

利用者は、普段どおりGoogle Docsで記録を作成し、必要な資料をGoogle Driveへ保存します。システムはそれらを共有ドライブ上で整理し、検索、面談準備、過去履歴確認、AIによる要約・論点抽出に利用できる形へ変換します。

このプロジェクトで重視することは、入力項目を増やすことではなく、既に作成されている記録を少ない操作で共有資産へ変えることです。

## 基本構成

- 利用者向けUI: AppSheetを第一候補とし、利用不可の場合はApps Script Web Appを採用
- 面談記録: Google Docs
- 面談資料: Google Drive
- 正式な保管場所: Google Workspaceの共有ドライブ
- 構造化データと索引: Google Sheets
- ファイル連携と自動処理: Google Apps Script
- AI処理: 会社承認済みのGemini APIまたはVertex AI
- 設計・ソースコード管理: GitHub

## 設計原則

1. 利用者の手入力を最小限にする
2. Spreadsheetを一般利用者に直接編集させない
3. Docsの書式を過度に固定せず、AI出力側を共通化する
4. AIの回答から必ず原資料へ戻れるようにする
5. 個人アカウント、個人Drive、個人APIキーに依存しない
6. 機密データ、認証情報、実際の面談記録をGitHubへ保存しない
7. 通常検索から開始し、必要性が確認された後に高度なRAGを導入する

## 現在のステータス

構想・要件整理段階です。実装開始前に、Google Workspace、共有ドライブ、AppSheet、Gemini APIまたはVertex AIの社内利用可否を確認します。

## 対象外

初期段階では、次の機能を対象外とします。

- Gmail全体の自動読込
- 共有ドライブ全体への無制限なAIアクセス
- AIによる正式記録の自動確定
- 高度なベクトル検索基盤の先行導入
- 投資判断資料の自動作成・自動承認

## リポジトリ運用上の注意

このリポジトリには設計書、ソースコード、テスト用の匿名化データのみを保存します。実際の面談記録、面談資料、個人情報、未公開ファンド情報、APIキー、認証情報は保存しません。
